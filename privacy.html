プライバシーポリシー / Privacy Policy

kirinuki は YouTube API サービスを使い、運営者自身の YouTube チャンネルへ動画・サムネイル・字幕を投稿します。

取得する情報：ログインした Google アカウントの YouTube チャンネルへの投稿に必要な許可（アクセストークン）のみです。

保存：トークンは運営者の PC の中だけに保存し、第三者に提供・共有しません。

許可の取り消し：https://myaccount.google.com/permissions からいつでも取り消せます。

本ツールは YouTube 利用規約 と Google プライバシーポリシー に従います。

kirinuki uses YouTube API Services only to upload videos, thumbnails and captions to the owner's own channels. Tokens are stored only on the owner's computer and are never shared.
